# Pizza Sales Analysis - Power BI 

This project involves analyzing pizza sales data using **Power BI** and **SQL**. The goal was to derive actionable insights from sales data and visualize the results through an interactive Power BI dashboard. Key components of the analysis include identifying **busiest days and times**, understanding **sales performance**, and recognizing **best and worst-selling items**.

### Key Features:
- **Data Collection & Processing**: Used SQL to extract and prepare data from the pizza sales database.
- **Visualizations**: Created multiple interactive visuals including bar charts, pie charts, and line graphs to analyze total revenue, orders, and pizzas sold.
- **Insights**:
  - Identified the **busiest days** (e.g., weekends, particularly Friday and Saturday evenings).
  - Analyzed **monthly trends** to determine peak sales months like July and January.
  - Highlighted top-selling items such as the **Classic Deluxe Pizza** and **Thai Chicken Pizza**, along with worst sellers like the **Brie Carre Pizza**.
- **Performance Metrics**: The dashboard includes important metrics like total revenue, average order value, and total orders.

### Tools & Technologies Used:
- **SQL** for data extraction and database queries.
- **Power BI** for data visualization and dashboard creation.
- **DAX** for creating calculated columns and measures.

# Sales Dashboard Project - Data Analysis

This project focuses on creating a comprehensive sales performance dashboard, providing insights into **order trends**, **pizza categories**, and **sizes**. The dashboard helps stakeholders understand how various factors impact pizza sales and make data-driven decisions for better inventory management and marketing strategies.

### Key Features:
- **Order Trends**: Analyzed total orders by day and month, highlighting peak sales periods.
- **Pizza Category Insights**: Broke down sales performance by pizza category, such as Classic, Supreme, Veggie, and Chicken.
- **Pizza Size Analysis**: Evaluated the popularity of different pizza sizes and their contribution to overall sales.
- **Sales Performance Metrics**: Included key performance indicators like average order value, total pizzas sold, and average pizzas per order.

### Tools & Technologies Used:
- **SQL** for data manipulation and querying.
- **Power BI** for creating the dashboard with interactive visualizations and data exploration.
- **DAX** for calculations such as revenue and order counts.
